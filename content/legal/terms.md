## The service

Pushguard watches the GitHub repositories you install it on, reviews the changes made to them, and raises alerts when a change looks like a known attack. Alerts are filed as issues in your repositories and can be sent to destinations you choose.

No tool catches every attack. Pushguard may miss malicious changes, and some alerts will turn out to be harmless. You remain responsible for reviewing changes to your code and for your own security decisions.

To find out what a suspicious package or script does, Pushguard may run code from your repository in an isolated, short-lived environment. Installing Pushguard means you allow this.
